# 🐎 Uma Tracker - 取扱説明書

ウマ娘のサークル活動を爆速化する、AI搭載ファン数管理・掲示板ツールです。

## 🌟 主要機能

### 1. 爆速ファン数報告 (Dashboard)
メイン画面でスクショを貼り付けるだけで、ファン数を自動加算します。
*   **操作**: `Alt + PrtSc` で撮影後、画面上で `Ctrl + V` するだけ。
*   **解析**: OCR機能により、画像から数値を抜き出して累積実績に加算します。

### 2. インテリジェント・パドック (Board)
AI解析付きの掲示板です。サークル内の知恵を結集させましょう。
*   **操作**: 「投稿する」ボタン、または掲示板エリアで `Ctrl + V`。画像は最大4枚まで貼れます。
*   **AI OCR**: 投稿された画像から、ウマ娘の名前、ステータス、脚質、因子などを自動で文字起こしします。
*   **SS連携**: 投稿内容は設定した Google スプレッドシートにリアルタイムで書き込まれます。

### 3. AIアドバイス (Analysis)
統計ボタンからAIによるパーソナライズされたアドバイスを受け取れます。
*   **機能**: 現在の目標達成率に基づき、AIがモチベーション向上のためのコメントを生成します。

## 🛠️ 初期設定ガイド

### 1. Discord 連携
ログインボタンからDiscordアカウントで認証してください。

### 2. Gemini APIキーの設定
AI解析（OCR・アドバイス）を利用するには、Google AI Studio で取得したAPIキーが必要です。
*   **設定場所**: 右上の管理者設定（歯車） > 「マスター設定」タブ > API Key欄に入力して保存。

### 3. スプレッドシート連携
投稿内容を自動保存する場合は、以下の手順が必要です。
1.  同梱の `gas_template.gs` の中身を Google Apps Script に貼り付けてデプロイ。
2.  発行されたURLを、`main.js` の `GAS_ENDPOINT` 変数に貼り付ける。

## 💡 トラブルシューティング

### 「容量がいっぱい」と出る場合
ブラウザの保存制限（LocalStorage）によるものです。
*   **対策**: 古い投稿の画像を自動で消去する「自己浄化システム」が内蔵されていますが、解決しない場合はスプレッドシート連携を優先し、ローカルのデータをリセットしてください。

### ログインできない場合
一度 `Ctrl + F5` でキャッシュを完全にクリアしてリロードしてください。
