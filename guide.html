Uma Tracker
Manual & Instructions

1. 招待とログイン

1

Discordアカウントを使用してログインします。ログイン後、既存のサークルを探すか、自分で新しいサークルを作成できます。

💡 Tip: サークル管理者は「Admin」画面からサークルの招待URLを設定でき、ログイン直後のポータルから簡単にDiscordへ飛べるようになります。

2. ファン数の記録 (OCR)

2

ゲーム内のプロフィール画面などをスクリーンショット（Alt + PrtSc）し、このアプリを開いて Ctrl + V (貼り付け) するだけでファン数が自動加算されます。

wallpaper

プロフィール画面の画像をそのまま貼り付けるだけ！

3. Trainers' Paddock

3

日々の育成報告や攻略情報を投稿できます。ハッシュタグ (#) を使うことで情報を整理でき、クリックで絞り込みも可能です。

🤖 AI Image Vision: 画像を添付して投稿すると、AIがその中身（ステータスやサポカなど）を解析し、最適なアドバイスをリプライします。

4. 智慧の継承 (AI Wisdom)

4

パドック（タイムライン）に投稿された攻略情報は、AIが自動的に要約し画面右側の「AI Wisdom」に蓄積します。これがサークル独自の攻略Wikiになります。

★ 権限と役割について

1. システム管理者（オーナー）
全サークル共通のAIキー設定やシステム全体を管理します。右上の盾アイコンから入ります。

2. サークル管理人（リーダー）
自分のサークルの名前、ノルマ、Webhookを管理します。「サークル管理」から入ります。

3. サークルメンバー（一般）
ファン数登録やつぶやき、Wiki閲覧を行います。特別な設定は不要です。

5. 管理者設定とGemini API

5

Admin画面で Google Gemini API Key を設定すると、分析精度が劇的に向上します。完全無料で本物のAI秘書を手に入れることができます。
